O que é este guia

Toda vez que você abre um site, uma conversa em rede acontece em milissegundos: seu computador vira um pacote, encontra o endereço IP do servidor pelo DNS, negocia uma conexão TCP e troca mensagens HTTP (ou HTTPS criptografado). Quem entende redes consegue diagnosticar "o site não abre", escolher portas, ler erros e falar com APIs.

  • Diagnosticar problemas: ping, dig, traceroute, curl -v, ss;
  • Entender IP, máscara, gateway, NAT e DHCP da sua própria rede;
  • Falar HTTP de verdade: métodos, headers, status, cookies e TLS;
  • Avançado: OSI/TCP-IP, BGP, VPN, firewall, CDN, HTTP/2 e HTTP/3.

Anatomia de uma URL

https://
O protocolo: HTTPS = HTTP + criptografia TLS.
exemplo.com
O domínio: um nome que o DNS traduz para um IP.
/caminho
O recurso pedido dentro do servidor.
:443
A porta (opcional na URL; 443 é a padrão do HTTPS).
