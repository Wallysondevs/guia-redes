O que é uma rede — e a internet

Toda vez que você abre um site ou manda uma mensagem, seus dados viram pequenas cartas numeradas (os pacotes) que viajam por cabos de rede, Wi-Fi e até cabos submarinos no fundo do mar até chegarem ao destino. Nesta aula você aprende a ideia de rede com a analogia do correio — e faz seus primeiros comandos no terminal simulado desta página.

Você vai aprender
  • O que é uma rede (dois ou mais computadores trocando dados) e o que é a internet (uma rede de redes).
  • A analogia do correio: carta = pacote, CEP = endereço IP, centro de distribuição = roteador.
  • O que é um pacote e por que um arquivo grande é quebrado em vários.
  • Quem é a máquina fictícia deste guia: ana@notebook na rede 192.168.1.0/24.
  • Seus dois primeiros comandos no simulador: help e ping exemplo.com.

A analogia do correio

Pense em mandar uma carta pelo correio:

  • A carta é o dado que você quer enviar — uma página, uma foto, um vídeo.
  • No envelope vão o endereço de quem envia e o endereço de quem recebe (o "CEP" de cada um).
  • O centro de distribuição dos correios lê o CEP e decide para onde encaminhar a carta — às vezes passando por 2 ou 3 centros antes do destino.
  • Se a carta é grande demais para um envelope, você quebra em várias cartas numeradas ("1 de 5", "2 de 5"…) e o destinatário junta tudo no fim.

Numa rede de computadores acontece exatamente a mesma coisa: o dado vira pacotes, cada pacote leva o IP de origem e o IP de destino, e os roteadores no meio do caminho encaminham cada pacote até o destino.

A internet é uma "rede de redes"

Uma rede é qualquer conjunto de computadores que consegue conversar — pode ser só o seu notebook e a sua impressora em casa. A internet é quando milhões de redes do mundo inteiro se conectam entre si por enlaces que cruzam cidades, países e oceanos (fibra óptica terrestre e cabos submarinos).

Na analogia de estradas: cada rede local é um quarteirão, os enlaces entre elas são as ruas e rodovias, e a internet é o mapa inteiro. Não existe "um computador da internet" — existem BILHÕES de máquinas ligadas por essas estradas, e o seu pacote escolhe o caminho salto a salto.

O que é um pacote

Quando você abre uma página de 2 MB, ela não viaja inteira de uma vez. Ela é quebrada em milhares de pacotes de cerca de 1500 bytes cada (o "envelope padrão" da rede, chamado MTU). Cada pacote tem um cabeçalho com as etiquetas — IP de origem, IP de destino, número de sequência — e uma parte com o conteúdo. Quem recebe junta os pacotes na ordem certa, como quem monta um quebra-cabeça numerado.

É por isso que, se a rede está ruim, uma página "carrega pela metade": alguns pacotes llegaron, outros se perderam no caminho e foram reenviados.

Seu primeiro comando: help

Toda caixa escura de terminal deste guia é um simulador — nada sai do seu navegador. Clique na caixa, digite help e aperte Enter para ver todos os comandos de rede disponíveis:

Missão: digite help e aperte Enter. Veja a lista de comandos de rede que o simulador entende.

$ help
Comandos disponíveis:
  ping HOST [-c N]      testa se o host responde
  curl [OPÇÕES] URL     faz requisição HTTP (use -i, -v, -X POST, -d '{}')
  dig HOST [TIPO]       consulta DNS (+short, +trace)
  ip addr | ip route    seus IPs e rotas
  ss -tlnp              portas abertas (escuta)
  …

E o primeiro ping

ping é o "alô, tem alguém aí?" da rede: ele manda um pacote de teste e mede se o outro computador responde e em quanto tempo. Experimente pingar um site:

Missão: digite ping exemplo.com e aperte Enter. Cada linha 64 bytes from … é uma resposta que voltou.

$ ping exemplo.com
PING exemplo.com (93.184.216.34) 56(84) bytes of data.
64 bytes from 93.184.216.34: icmp_seq=1 ttl=64 time=23.4 ms
64 bytes from 93.184.216.34: icmp_seq=2 ttl=64 time=22.9 ms
64 bytes from 93.184.216.34: icmp_seq=3 ttl=64 time=24.1 ms
64 bytes from 93.184.216.34: icmp_seq=4 ttl=64 time=23.0 ms

--- exemplo.com ping statistics ---
4 packets transmitted, 4 received, 0% packet loss, time 3000ms

Repare nas partes: o nome exemplo.com foi traduzido para o IP 93.184.216.34 (isso é o DNS, próxima aula), cada resposta mostra ttl=64 (quantos roteadores o pacote ainda pode atravessar) e o time (ida e volta em milissegundos).

Resumo

  • Rede = computadores trocando dados; internet = a rede de todas as redes, ligada por enlaces que cruzam o mundo.
  • Analogia do correio: dado = carta, pacote = envelope com IP de origem e destino, roteador = centro de distribuição.
  • Arquivos grandes são quebrados em pacotes de ~1500 bytes e remontados no destino.
  • A máquina deste guia é ana@notebook, IP 192.168.1.50/24, gateway 192.168.1.1.
  • Primeiros comandos no simulador: help (lista de comandos) e ping exemplo.com (o host responde?).
