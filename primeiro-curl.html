Seu primeiro curl

O curl é a canivete suíço da linha de comando: ele faz o papel do navegador — fala HTTP com um servidor e traz a resposta para o seu terminal. Nesta aula você faz o seu primeiro pedido de página com curl -i (mostrando os cabeçalhos) e descobre que dá para chamar APIs também, que respondem em JSON.

Você vai aprender
  • O que o curl faz: envia uma requisição HTTP para uma URL e imprime a resposta.
  • A diferença de curl URL (só o corpo) para curl -i URL (cabeçalhos + corpo).
  • Ler a resposta: HTTP/2 200, cabeçalhos como content-type e o corpo HTML.
  • Chamar uma API e receber JSON (dados puros, não página).
  • Que curl exemplo.com completa http:// sozinho.

O primeiro pedido: cabeçalhos + corpo

Com a opção -i, o curl imprime os cabeçalhos da resposta antes do conteúdo — é a conversa inteira do HTTP:

$ curl -i https://exemplo.com
HTTP/2 200
server: nginx/1.25.3
content-type: text/html; charset=UTF-8
strict-transport-security: max-age=31536000

<html><head><title>Exemplo</title></head><body><h1>Exemplo.com (HTTPS)</h1></body></html>

Peças: a primeira linha HTTP/2 200 é o status (deu certo); os cabeçalhos dizem o servidor (nginx), o tipo do conteúdo (text/html) e o HSTS (obrigação de usar HTTPS); depois da linha em branco vem o corpo: o HTML da página.

Missão: digite curl -i https://exemplo.com e aperte Enter. Você pediu a página como se fosse o navegador e recebeu HTTP/2 200 + cabeçalhos + HTML.

Só o corpo, sem cabeçalho

Sem o -i, o curl imprime só o corpo — só o conteúdo, pronto para ser usado:

$ curl https://exemplo.com
<html><head><title>Exemplo</title></head><body><h1>Exemplo.com (HTTPS)</h1></body></html>

Chamando uma API: a resposta em JSON

Nem toda URL devolve página HTML — APIs devolvem dados puros em JSON. Experimente a API fictícia do simulador:

$ curl https://api.exemplo.com/usuarios
[{"id":1,"nome":"Ana"},{"id":2,"nome":"Beto"},{"id":3,"nome":"Carla"}]

Repare: é só texto com cara de lista de objetos — "nome":"Ana" etc. É assim que apps pegam dados de servidores (previsão do tempo, saldo do banco, mensagens…).

Missão: digite curl https://api.exemplo.com/usuarios e aperte Enter. A API devolve a lista em JSON, começando por {"id":1,"nome":"Ana"}.

Detalhes de uso

  • Sem protocolo, o curl assume HTTP: curl exemplo.com = curl http://exemplo.com.
  • Se o nome não existe no DNS, o erro aparece na hora: curl: (6) Could not resolve host: ….
  • Outras opções que você vai usar já já: -v (mostra a conversa inteira), -I (só os cabeçalhos), -X POST -d '…' (envia dados), -o arquivo (salva no arquivo).

Resumo

  • curl URL faz uma requisição HTTP e imprime a resposta — é o navegador da linha de comando.
  • curl -i mostra os cabeçalhos (status HTTP/2 200, tipo do conteúdo) + o corpo; sem -i, vem só o corpo.
  • Sites devolvem HTML; APIs devolvem JSON (dados puros), como api.exemplo.com/usuarios.
  • Sem protocolo na URL, o curl completa com http://.
