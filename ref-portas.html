Portas comuns (cola)

Se o IP é o endereço do prédio, a porta é a sala dentro do prédio: o mesmo computador (IP 192.168.1.50) pode ter o servidor web na sala 80, o SSH na sala 22 e o banco na sala 3306, tudo ao mesmo tempo. Esta cola lista as portas que você vai encontrar toda hora.

Você vai aprender
  • As portas bem-conhecidas (0–1023): 20/21, 22, 25, 53, 80, 443…
  • As portas registradas de bancos e filas: 3306, 5432, 6379, 27017…
  • As portas de desenvolvimento: 3000, 8000, 8080, 8888…
  • A diferença entre porta TCP e UDP na mesma numeração (ex.: 53 nos dois).
  • Como ver as portas da sua máquina: ss -tlnp e nc -zv.

Como as portas são divididas

0–1023 · bem-conhecidas (well-known)
Reservadas para serviços padrão do sistema (SSH, HTTP, DNS…). Só o root consegue abrir uma porta aqui.
1024–49151 · registradas
Atribuídas a programas específicos por registro (MySQL 3306, PostgreSQL 5432, Redis 6379…). Qualquer programa pode usar, mas é "de alguém".
49152–65535 · dinâmicas/privadas
Usadas pelo seu computador como porta de origem temporária em cada conexão que ele inicia (ephemeral).

Uma porta pode existir em TCP e UDP ao mesmo tempo, separadamente — o DNS, por exemplo, usa UDP 53 para consultas rápidas e TCP 53 para respostas grandes (transferência de zona).

Veja as portas da sua máquina agora

$ ss -tlnp
Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:Port Process
TCP   LISTEN 0      128    0.0.0.0:22           0.0.0.0:*     users:(("sshd",1012))
TCP   LISTEN 0      128    0.0.0.0:8000         0.0.0.0:*     users:(("python3",2031))
$ nc -zv localhost 8000
Connection to localhost 8000 port [tcp/*] succeeded!

Leitura: 0.0.0.0:8000 = ouvindo em todos os IPs na porta 8000; 127.0.0.1:3000 seria só para o próprio computador (mais seguro para bancos de dados em desenvolvimento).

Missão: rode ss -tlnp no simulador e ache a porta 8000 (e a 22) em LISTEN.

Missão: teste uma porta remota: rode nc -zv exemplo.com 443 e veja succeeded!.

Resumo

  • Porta = a sala dentro do prédio (IP). TCP e UDP são corredores separados com a mesma numeração.
  • 0–1023 bem-conhecidas (22 SSH, 53 DNS, 80 HTTP, 443 HTTPS), 1024–49151 registradas (3306, 5432, 6379), 49152+ dinâmicas.
  • Veja as suas com ss -tlnp; teste uma porta com nc -zv HOST PORTA.
  • Porta de banco aberta para o mundo (0.0.0.0) é um risco — restrinja a 127.0.0.1 ou ao firewall.
