Comandos ip addr e ip route

Quem é a máquina na rede? Quais IPs ela tem e por onde saem os pacotes? O comando ip responde as duas perguntas: ip addr mostra os endereços (o "CEP" dela) e ip route mostra as rotas (os "caminhos" que os pacotes pegam). Nesta aula, tudo isso na máquina da Ana.

Você vai aprender
  • ip addr (ou ip a): as interfaces de rede e seus IPs — lo (127.0.0.1) e eth0 (192.168.1.50/24).
  • Ler a saída: inet (o IP/máscara), link/ether (o MAC) e state UP.
  • ip route (ou ip r): a tabela de rotas — default via 192.168.1.1 (o gateway) e a rede local.
  • Por que "default via …" é a porta de saída da rede local.
  • Os comandos antigos equivalentes: ifconfig e route -n.

ip addr: os endereços da máquina

Cada placa de rede do computador é uma interface com seu próprio IP. O notebook da Ana tem duas:

$ ip addr
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 1500 qdisc noqueue state UNKNOWN
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue state UP
    link/ether aa:bb:cc:dd:ee:ff brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.50/24 scope global eth0
1: lo
A interface loopback: sempre existe, aponta para a própria máquina (127.0.0.1).
2: eth0
A placa de rede real (Ethernet/Wi-Fi), aqui state UP = ligada e funcionando.
link/ether aa:bb:cc:dd:ee:ff
O endereço MAC: a identidade física da placa na rede local (único no mundo).
inet 192.168.1.50/24
O IPv4 da máquina + a máscara /24: "sou a casa 50 da rua 192.168.1".
scope global
O endereço vale para fora da máquina (diferente de scope host, só local).

Missão: digite ip addr e aperte Enter. Ache a linha inet 192.168.1.50/24 scope global eth0 — o CEP do notebook da Ana.

ip route: para onde vão os pacotes

A tabela de rotas é o GPS da máquina: diz por qual caminho cada pacote sai. Na rede da Ana:

$ ip route
default via 192.168.1.1 dev eth0 proto dhcp metric 100
192.168.1.0/24   dev eth0 proto kernel scope link src 192.168.1.50 metric 100
default via 192.168.1.1
A rota padrão: tudo que não é da rede local vai para o gateway (o roteador). É a "porta de saída" da casa.
dev eth0
O pacote sai pela interface eth0 (a placa de rede).
192.168.1.0/24 … src 192.168.1.50
A rota da rede local: pacotes para 192.168.1.x vão direto, sem passar pelo gateway.

Resumo da lógica: "se o destino está na minha rua (192.168.1.x), vou direto; se não está, mando para o porteiro (gateway 192.168.1.1) e ele que se vire".

Missão: digite ip route e aperte Enter. A primeira linha deve ser default via 192.168.1.1 dev eth0… — a rota padrão pelo roteador.

Os comandos antigos (ainda existem)

Antes do ip, usava-se ifconfig e route -n — muitos tutoriais ainda ensinam eles, e fazem a mesma coisa:

$ ifconfig        « mesmo conteúdo do ip addr
… inet 192.168.1.50/24 …
$ route -n        « mesma tabela de rotas, formato antigo
Kernel IP routing table
Destination     Gateway         Genmask         Flags Metric Ref    Use Iface
default         192.168.1.1     0.0.0.0         UG    100    0        0 eth0
192.168.1.0     0.0.0.0         255.255.255.0   U     100    0        0 eth0

Resumo

  • ip addr lista interfaces e IPs: lo = 127.0.0.1 (si mesma), eth0 = 192.168.1.50/24 + MAC.
  • ip route mostra as rotas: default via 192.168.1.1 (gateway, saída para a internet) e a rede local 192.168.1.0/24 (entrega direta).
  • Se ip addr não mostra IP em eth0, a máquina não pegou IP (aí entra o DHCP, no Nível 2).
  • Equivalentes antigos: ifconfig e route -n.
