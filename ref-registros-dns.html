Tipos de registro DNS (cola)

O DNS é como uma agenda telefônica gigante e distribuída: cada domínio tem vários "cartões" (registros), e cada tipo de registro guarda uma informação diferente — para qual IP o site aponta, para onde vão os e-mails, qual o apelido… Esta cola lista os tipos que você vai encontrar toda hora e como consultar cada um com dig.

Você vai aprender
  • Os registros principais: A, AAAA, CNAME, MX, TXT, NS, SOA, PTR, SRV, CAA.
  • Como consultar cada tipo: dig exemplo.com MX, dig exemplo.com TXT, dig -x 93.184.216.34 (PTR)…
  • A diferença entre A (IPv4) e AAAA (IPv6), e por que CNAME não pode coexistir com outros registros no mesmo nome.
  • O que é TTL (o "tempo de validade" do cartão na agenda) e por que mudanças de DNS demoram para valer.

Exemplos reais no terminal

$ dig exemplo.com +short
93.184.216.34
$ dig exemplo.com
;; ->>HEADER<<- opcode: QUERY, status: NOERROR
;; ANSWER SECTION:
exemplo.com.            3600    IN      A       93.184.216.34
;; Query time: 12 msec
;; SERVER: 192.168.1.1#53(192.168.1.1)
$ dig exemplo.com MX
;; ANSWER SECTION:
exemplo.com.            86400   IN      MX      10 mail.exemplo.com.

Missão: rode dig exemplo.com (sem +short) e ache status: NOERROR no cabeçalho + o registro A na ANSWER SECTION.

Missão: agora rode dig exemplo.com +short e veja que a saída fica só com o IP: 93.184.216.34.

Detalhes que fazem diferença

TTL (time to live)
O número antes do IN (ex.: 3600) é o tempo em segundos que o resultado fica em cache. Mudar um registro com TTL alto demora para valer em todo lugar — é a propagação de DNS.
CNAME não divide cartão
Se www é CNAME de exemplo.com, o www não pode ter A/MX/TXT próprios ao mesmo tempo — o DNS segue o apelido até o fim.
A vs AAAA
O mesmo nome pode ter os dois: o navegador tenta o IPv6 (AAAA) primeiro e cai no IPv4 (A) se não houver rota IPv6.
PTR (reverso)
Usado por servidores de e-mail para validar que o IP realmente pertence ao domínio que envia a mensagem (anti-spam).
Nome raiz
Todo nome termina com ponto: exemplo.com. — a raiz vazia. O +short esconde isso; o dig completo mostra.

Resumo

  • A/AAAA = IP (v4/v6); CNAME = apelido; MX = e-mail; TXT = texto (SPF/verificação); NS/SOA = autoridades do domínio; PTR = reverso; SRV = serviço+porta; CAA = quem emite SSL.
  • Consulte com dig TIPO: dig exemplo.com A +short, dig exemplo.com MX, dig -x IP.
  • Nome inexistente = NXDOMAIN (veja problemas comuns).
