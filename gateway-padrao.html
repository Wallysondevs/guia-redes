Gateway padrão: a porta de saída da rede

Pense no seu prédio: dentro dele, você fala direto com o vizinho do apartamento 50 — só precisa saber o número do apto. Mas para entregar uma carta a qualquer outro lugar do mundo, você precisa passar pela portaria. O gateway padrão é a portaria da sua rede: todo pacote cujo destino está fora da sua sub-rede é entregue a ele, e ele sabe continuar o caminho.

Você vai aprender
  • Como a tabela de rotas decide: destino na rede local → entrega direta; resto → gateway padrão.
  • A ler ip route e route -n: a linha default via 192.168.1.1.
  • A anatomia da rota padrão: default via GATEWAY dev IFACE proto dhcp.
  • O que acontece quando não existe gateway padrão.

A tabela de rotas na prática

Todo computador tem uma tabela de rotas — uma lista de regras "para este destino, faça assim". Na máquina da Ana há duas regras:

$ ip route
default via 192.168.1.1 dev eth0 proto dhcp metric 100
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.50 metric 100
RotaSignificadoExemplo de destino
192.168.1.0/24 dev eth0 … src 192.168.1.50Destino dentro da rede local → entrega direta pela placa eth0 (via ARP, aula ARP)ping 192.168.1.1, ping 192.168.1.60
default via 192.168.1.1 dev eth0Todo o resto (a rota "padrão") → manda para o gateway 192.168.1.1ping 8.8.8.8, exemplo.com, qualquer site

Anatomia da linha de rota padrão

default
Apelido para 0.0.0.0/0 — "qualquer destino que não casou com outra rota mais específica".
via 192.168.1.1
O endereço do gateway padrão (o roteador): para onde o pacote é encaminhado.
dev eth0
A placa de rede por onde o pacote sai.
proto dhcp
Quem configurou essa rota: o DHCP entregou esse gateway automaticamente.
metric 100
Prioridade da rota (quando há várias, vale a de menor métrica).

O formato antigo, com route -n, mostra a mesma coisa com máscara:

$ route -n
Kernel IP routing table
Destination     Gateway         Genmask         Flags Metric Ref    Use Iface
default         192.168.1.1     0.0.0.0         UG    100    0        0 eth0
192.168.1.0     0.0.0.0         255.255.255.0   U     100    0        0 eth0

Na linha da rede local, Gateway 0.0.0.0 significa "entrega direta, sem gateway". Na linha default, Gateway 192.168.1.1 com flag UG (Up + Gateway) é a porta de saída.

Missão: rode ip route e ache a linha default via 192.168.1.1 — essa é a porta de saída da rede da Ana.

Missão: rode ping 8.8.8.8. O 8.8.8.8 está fora da rede local, então o pacote foi entregue ao gateway 192.168.1.1 (e voltou a resposta).

Missão: agora rode ping 192.168.1.1 — destino dentro da rede local: esse pacote foi direto, sem passar pelo gateway.

Sem gateway padrão, só existe a rede local

Se a rota default sumir (erro de DHCP, configuração manual incompleta), o computador continua pingando os vizinhos (192.168.1.x) — mas ping 8.8.8.8 e qualquer site falham com "Network is unreachable". É o sintoma clássico: Wi-Fi conectado, internet morta = falta gateway (ou DNS).

Resumo

  • Gateway padrão = para onde vão os pacotes com destino fora da sub-rede local (a "portaria").
  • Na rede da Ana: default via 192.168.1.1 dev eth0 proto dhcp.
  • Destino dentro de 192.168.1.0/24 → entrega direta (gateway 0.0.0.0 na tabela).
  • Veja com ip route ou route -n; sem default, só a rede local funciona.
