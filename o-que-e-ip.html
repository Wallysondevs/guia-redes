Endereço IP: o "CEP" do computador (IPv4)

No correio, cada casa tem um CEP único. Na rede, cada máquina tem um endereço IP único — é o "CEP" dela. Nesta aula você aprende o formato IPv4 (quatro números de 0 a 255), o que é a máscara /24, e vê o IP do notebook da Ana: 192.168.1.50.

Você vai aprender
  • O que é um IPv4: 4 octetos, 32 bits, de 0.0.0.0 a 255.255.255.255.
  • A analogia do CEP: o IP identifica quem é a máquina na rede.
  • Máscara de rede /24: a parte do IP que é a "rua" (rede) e a parte que é a "casa" (máquina).
  • 127.0.0.1: o endereço que aponta para a própria máquina (loopback).
  • IP privado (192.168…) vs IP público — uma rápida introducción.
  • Ver os IPs da máquina com ip addr e pingar o gateway 192.168.1.1.

O formato IPv4: quatro números

Um endereço IPv4 é formado por 4 números de 0 a 255 separados por ponto — são 4 "octetos" de 8 bits, ou 32 bits no total:

192

168

1

.

50
4º octeto — a "casa" dentro da rua

Na analogia do CEP: 192.168.1 é como o bairro/rua, e o último número (50) é a casa específica. Por isso o notebook da Ana se chama 192.168.1.50 — e o roteador da casa dela é o vizinho 192.168.1.1.

A máscara /24: onde termina a rua e começa a casa

O IP vem sempre com uma máscara escrita assim: /24. Esse número diz quantos bits são da rede e quantos são da máquina:

  • 192.168.1.50/24 → os 24 primeiros bits (192.168.1) identificam a rede; os 8 últimos bits (50) identificam a máquina dentro dela.
  • Na rede 192.168.1.0/24 cabem 254 máquinas: de 192.168.1.1 até 192.168.1.254.

É como o CEP + complemento: o CEP diz a rua, o complemento diz o número exato da casa.

Veja os IPs da sua máquina: ip addr

O comando ip addr (ou só ip a) lista as interfaces de rede — as "placas" do computador — e os IPs de cada uma. Na máquina da Ana existem duas:

  • lo (loopback): o endereço 127.0.0.1, que aponta para a própria máquina — serve para um programa conversar consigo mesmo sem sair de casa.
  • eth0: a placa de rede de verdade, com o IP 192.168.1.50/24 e o endereço físico (MAC) aa:bb:cc:dd:ee:ff.
$ ip addr
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 1500 qdisc noqueue state UNKNOWN
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue state UP
    link/ether aa:bb:cc:dd:ee:ff brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.50/24 scope global eth0

Missão: digite ip addr e aperte Enter. Procure a linha inet 192.168.1.50/24 da interface eth0 — esse é o "CEP" do notebook da Ana.

Ping no vizinho: o gateway 192.168.1.1

Todo pacote que vai fora da rede local passa primeiro pelo gateway (roteador) — na rede da Ana, o 192.168.1.1. Pingar o gateway é o primeiro teste de "minha rede local está viva":

$ ping 192.168.1.1
PING 192.168.1.1 (192.168.1.1) 56(84) bytes of data.
64 bytes from 192.168.1.1: icmp_seq=1 ttl=64 time=1.42 ms
64 bytes from 192.168.1.1: icmp_seq=2 ttl=64 time=1.18 ms

--- 192.168.1.1 ping statistics ---
2 packets transmitted, 2 received, 0% packet loss, time 1001ms

Repare no time=1.42 ms: como o roteador está na mesma rede local, a resposta vem em 1–4 ms. Quando pingarmos um site na internet, o tempo sobe para dezenas de milissegundos — é a "distância" até lá.

Missão: digite ping 192.168.1.1 e aperte Enter. Se o gateway responder com 64 bytes from 192.168.1.1, sua rede local está no ar.

IP privado e IP público (rapidamente)

Endereços que começam com 192.168…, 10… ou 172.16–31… são privados: só existem dentro de uma rede local (casa, empresa, escola) e se repetem em milhões de lugares. Já um IP como 93.184.216.34 é público: único no mundo inteiro, roteável na internet. Quem faz a ponte entre os dois é o NAT do roteador (você verá no Nível 2).

Resumo

  • IPv4 = 4 números de 0 a 255 (32 bits): é o "CEP" único da máquina na rede. O da Ana é 192.168.1.50.
  • A máscara /24 separa a parte da rede (192.168.1) da parte da máquina (.50).
  • 127.0.0.1 (loopback) aponta para a própria máquina.
  • ip addr mostra as interfaces (lo, eth0), os IPs e o MAC; ping 192.168.1.1 testa o gateway local.
