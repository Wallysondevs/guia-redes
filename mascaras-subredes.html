Máscara de sub-rede: o que é /24?

A máscara de sub-rede é a régua que separa o endereço em duas partes: qual parte identifica a rede (o prédio) e qual parte identifica o computador dentro dela (o apartamento). Pense numa rua com 256 casas numeradas de 0 a 255: o número da rua é a parte de rede, o número da casa é a parte do host. O /24 diz exatamente onde essa divisão acontece.

Você vai aprender
  • O que significam 255.255.255.0 e a notação CIDR /24.
  • A calcular quantos hosts cabem num prefixo: 2^(32−n) − 2 (tirando rede e broadcast).
  • Os endereços especiais de cada sub-rede: endereço de rede e broadcast.
  • A tabela dos prefixos mais usados (/8, /16, /24, /25, /26… /30).
  • Como ver a máscara da sua rede com ip addr e route -n.

De binário para a notação /n

Uma máscara como 255.255.255.0 em binário é 11111111.11111111.11111111.00000000 — uma fileira de 24 uns seguida de 8 zeros. O CIDR simplesmente conta os uns: 255.255.255.0 = /24. Quanto mais uns, menor a rede e mais bits sobram para os hosts? Não — o contrário: quanto maior o /n, menor a rede (mais bits de rede, menos de host).

192.168.1.50
O endereço IP da máquina (32 bits).
/24
O prefixo: os primeiros 24 bits são a rede; os últimos 8 bits são o host.
255.255.255.0
A mesma coisa escrita em máscara: 24 uns + 8 zeros.

Calculando a rede da Ana: 192.168.1.0/24

Com /24, sobram 8 bits para o host: 2⁸ = 256 endereços. Dois deles são reservados:

  • 192.168.1.0 — o endereço de rede (identifica a rede inteira; ninguém usa como máquina).
  • 192.168.1.255 — o endereço de broadcast (fala com todas as máquinas da rede de uma vez, ex.: o ARP da aula ARP).

Sobram 256 − 2 = 254 hosts utilizáveis: de 192.168.1.1 até 192.168.1.254. Na rede da Ana, o .1 é o roteador (gateway) e o .50 é o notebook dela.

Exemplo de cálculo passo a passo: /26

Se a rede da Ana fosse 192.168.1.0/26:

  • Bits de host: 32 − 26 = 6 bits → 2⁶ = 64 endereços.
  • Hosts utilizáveis: 64 − 2 = 62 (de 192.168.1.1 a 192.168.1.62).
  • Rede: 192.168.1.0; broadcast: 192.168.1.63.
  • E um /24 inteiro comporta 256 ÷ 64 = 4 sub-redes /26: .0–.63, .64–.127, .128–.191, .192–.255.

É assim que se "corta" uma rede grande em pedaços menores (sub-redes) sem desperdiçar IPs — cada andar do prédio vira uma sub-rede.

Como ver a máscara no seu computador

$ ip addr
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue state UP
    link/ether aa:bb:cc:dd:ee:ff brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.50/24 scope global eth0      « o /24 é o prefixo CIDR
$ route -n
Kernel IP routing table
Destination     Gateway         Genmask         Flags Metric Ref    Use Iface
default         192.168.1.1     0.0.0.0         UG    100    0        0 eth0
192.168.1.0     0.0.0.0         255.255.255.0   U     100    0        0 eth0   « Genmask = a máscara da rede local

O ip addr mostra o formato moderno (/24); o route -n mostra o formato antigo (Genmask 255.255.255.0). São a mesma coisa.

Missão: rode ip addr e confirme que o notebook da Ana está em 192.168.1.50/24.

Missão: rode route -n e ache a coluna Genmask com 255.255.255.0 — a máscara da rede 192.168.1.0/24.

Cuidado ao mudar a máscara

Se o notebook da Ana fosse configurado como 192.168.1.50/25 (máscara 255.255.255.128), a rede seria outra: de 192.168.1.0 a 192.168.1.127. Um vizinho em 192.168.1.200 ficaria fora da sub-rede dela — e a comunicação pararia mesmo os dois estando no mesmo Wi-Fi. Máscara errada = "rede invisível".

Resumo

  • Máscara 255.255.255.0 = /24: 24 bits de rede + 8 de host.
  • Fórmula: endereços = 2^(32−n); hosts utilizáveis = 2^(32−n) − 2 (rede e broadcast não contam).
  • Em 192.168.1.0/24: rede = .0, hosts de .1 a .254, broadcast = .255.
  • Veja com ip addr (formato /24) e route -n (coluna Genmask).
