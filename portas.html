Portas: cada serviço tem seu número

Um computador tem um IP, mas roda vários serviços ao mesmo tempo: navegador, SSH, servidor de arquivos… Se o IP é o endereço do prédio, a porta é a sala onde cada serviço atende. Nesta aula: o que é uma porta (0–65535) e como testar se a sala está aberta.

Você vai aprender
  • O que é uma porta: um número de 0 a 65535 que identifica o serviço dentro da máquina.
  • A analogia do prédio: IP = endereço do prédio, porta = sala do serviço (80 = web, 443 = web segura, 22 = SSH).
  • As portas mais comuns e para que sirven.
  • Porta de origem vs porta de destino: a conversa tem duas pontas.
  • Testar portas abertas com nc -zv e nmap no simulador.

A analogia do prédio

O servidor exemplo.com mora no IP 93.184.216.34 — esse é o prédio. Dentro desse prédio há várias salas:

  • Sala 80: o porteiro do site comum (HTTP).
  • Sala 443: o porteiro do site seguro (HTTPS).
  • Sala 22: a entrada administrativa (SSH, acesso remoto).
  • Sala 53: a telefonista (DNS).

Quando seu navegador fala com o site, ele não bate só no prédio: bate na sala certa. A URL https://exemplo.com usa a sala 443; http://exemplo.com usa a sala 80. É por isso que na internet se diz "a porta 443 está aberta".

Os números: 0 a 65535

Porta é um número de 16 bits: vai de 0 a 65535. As de 0 a 1023 são bem-conhecidas (reservadas para serviços padrão, como 80 e 443); as outras qualquer programa pode usar (o servidorzinho da Ana usa a 8000).

Toda conversa tem duas portas

Quando o navegador da Ana fala com exemplo.com, a conversa tem duas pontas:

  • Porta de destino: a sala do servidor — 443 no caso do HTTPS.
  • Porta de origem: uma porta aleatória e livre do computador dela (ex.: 51234) — é por onde a resposta volta.

É como uma ligação telefônica: o número que você disca (destino) e o seu próprio número (origem).

Testando se a sala está aberta: nc e nmap

O comando nc -zv HOST PORTA (netcat) testa só uma porta: bate na sala e vê se alguém atende:

$ nc -zv exemplo.com 443
Connection to exemplo.com 443 port [tcp/*] succeeded!

O nmap faz o "scanner de salas": testa várias portas de uma vez e lista quais estão abertas:

$ nmap exemplo.com
Nmap scan report for exemplo.com (93.184.216.34)
Host is up (0.023s latency).
PORT    STATE  SERVICE
80/tcp  open   http
443/tcp open   https

Nmap done: 1 IP address (1 host up) scanned in 2.41 seconds

Missão: digite nc -zv exemplo.com 443 e aperte Enter. Se aparecer succeeded!, a sala 443 do servidor está aberta.

Missão: agora rode nmap exemplo.com e veja o scanner listar as portas abertas (80 e 443) até imprimir Nmap done.

Scaneie só o que é seu.

Rodar nmap em servidores que não são seus pode ser considerado invasão — muitos provedores bloqueiam quem faz scan. Use essas ferramentas nos seus computadores, em máquinas de laboratório ou em alvos autorizados (existem sites como o scanme.nmap.org feitos para treino).

Resumo

  • Porta = número de 0 a 65535 que identifica o serviço dentro da máquina. IP = prédio, porta = sala.
  • Principais: 22 SSH, 53 DNS, 80 HTTP, 443 HTTPS, 8000 servidor de desenvolvimento.
  • Toda conversa tem porta de destino (a sala do servidor) e porta de origem aleatória (por onde a resposta volta).
  • nc -zv HOST PORTA testa uma porta; nmap HOST escaneia várias. Só use em máquinas autorizadas.
